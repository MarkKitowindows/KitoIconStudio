# Kito Icon Studio 0.2.3 — исправление запуска

Исправлен ошибочный ресурс `SystemColors.MenuHighlightTextBrushKey` в `MainWindow.xaml`, который вызывал исключение ResourceDictionary при запуске. Векторные иконки инструментов, подписи на русском и английском, цветовая палитра и оформление меню сохранены.

## Запуск
1. Распакуйте архив в отдельную папку.
2. Откройте `KitoIconStudio.sln` в Visual Studio 2026.
3. Выполните **Сборка → Пересобрать решение**, затем **F5**.

Если проект остаётся со старой сборкой, удалите временные папки `bin` и `obj` **в копии проекта**, затем повторите сборку.
